# Project instructions

- Make changes on a topic branch and pass them to main through a pull request. Squash merge after verification.
- Keep secrets and runtime settings out of source and Git. Configure the provider, model, limits, timeouts, and service endpoints through the environment or external deployment settings. Make secrets available only on the server through environment variables or a secret manager.
- A checked-in environment example may list variable names with empty values. Catalogs, recipes, schemas, and interface copy are source-controlled product data and contracts.
- Write all repository files and bundled UI copy in English. Keep personal data, photos, real annotations, consent records, and live label text out of the repo, PRs, issues, and logs.
- Use synthetic sample data in Git. Inspect staged content and filenames before pushing.
